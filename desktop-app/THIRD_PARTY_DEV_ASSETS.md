# Live2D 第三方开发资源

`npm run setup:live2d-dev` 会从仓库归档标签恢复 Hiyori Momose 样例数据和 Live2D Cubism Core，仅用于本地开发与 SDK 集成验证。

> This content uses sample data owned and copyrighted by Live2D Inc.

生成目录为 `src/renderer/assets/dev-live2d/`。该目录受 Git 忽略，并由 `electron-builder.yml` 明确排除，不会默认进入 `.exe` 或 `.dmg`。

使用或发布相关资源前，请阅读：

- [Live2D Cubism 样例数据使用条款](https://www.live2d.com/en/learn/sample/model-terms/)
- [Live2D SDK 发布许可](https://www.live2d.com/en/sdk/license/)
- [Live2D Cubism SDK for Web 下载与许可](https://www.live2d.com/en/sdk/download/web/)

Hiyori Momose 属于 Live2D 原创样例角色，不得修改角色设计。正式发布应用前，需要根据发布主体、商业规模和应用是否允许扩展模型重新确认许可范围。
